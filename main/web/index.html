Settings file

Export saves every setting to a file. The Wi-Fi password is left out unless ticked below (the file may travel). Import checks the whole file first: if any value is refused, nothing changes.

Valve service and the compressor test work only with airflow mode OFF (Control tab).

Valve service

Hold − or + to jog. While you hold, the page repeats the jog every 150 ms; the valve driver stops the motor by itself 0.3 s after the last repeat. So if the phone, this page or the Wi-Fi drops, the motor stops. Releasing also sends STOP.

Sensor roles

Compressor test

Electric compressor only. The controller ends the test 60 s after the last command; this page repeats it every 20 s while the Service tab is open and in front, and ends it when you leave the tab. Interlocks (blower, minimum off time, freeze limits, link) stay active.

Service settings

Settings tab, group "Service" (changes only with mode OFF).
